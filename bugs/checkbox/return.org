* Bug Report

** Expected Behavior
  - checkboxes shouldn't change their states when the notes are not saved

** Actual Behaviour
  - when the notes are not updated, checkboxes get updated

** Steps to Reproduce
  1. Open the app.
  2. Go to the main page.
  3. Create a new note. (Existing note will also work.)
  4. Toggle the checkbox.
  5. Don't add any price. Simply come back.
