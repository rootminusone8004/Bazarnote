* Bug Report

** Expected Behavior
  Duplicate notes should appear if they are in separate sessions

** Actual Behaviour
  Duplicate notes don't appear in separate sessions

** Steps to Reproduce
  1. Open the app.
  2. Go to any existing session or create a new session and navigate there.
  3. Create a new note. Remember the name.
  4. Return to session page.
  5. Create another new session.
  6. Try to create a new note with that remembered name.
